# Product Overview

This repository contains AWS AI/ML solution examples and use cases created by AWS Specialist Solution Architects. It provides practical implementations for Amazon Bedrock, Amazon SageMaker, and related AWS AI/ML services.

## Repository Structure

The repository is organized into three main sections:

- **blog/**: Production-ready implementations with full CDK infrastructure (e.g., Aurora Vector Knowledge Base with multi-embedding support)
- **labs/**: Interactive Jupyter notebooks for experimental use cases and learning (e.g., Strands Agents with big data)
- **usecases/**: Focused implementations demonstrating specific patterns (e.g., MCP servers for cost analysis and time-off requests)

## Key Technologies

- **Amazon Bedrock**: Foundation models and agentic AI capabilities
- **Strands Agents**: Framework for building AI agents with tools and workflows
- **Model Context Protocol (MCP)**: Standard for AI assistant tool integration
- **Amazon Bedrock AgentCore**: Serverless runtime for deploying AI agents
- **FastMCP**: Python framework for building MCP servers
- **AWS CDK**: Infrastructure as Code for deployable solutions

## Target Audience

AWS users looking for practical examples of AI/ML implementations, from experimental notebooks to production-ready infrastructure code.
